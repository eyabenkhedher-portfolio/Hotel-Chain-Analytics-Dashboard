# hotel-booking-analysis
- **Hotel Booking Data Profiling & Analytics:** Cleaning complex relational databases and analyzing occupancy rates, revenues, and ratings using SQL Server.
### 🚀 Portfolio Projects

#### 🏨 Hotel Booking Data Profiling & Analytics (SQL Server)
* **Description:** Cleaned multi-table relational datasets (`dim_hotels`, `fact_bookings`) and calculated key hospitality performance metrics.
* **Key Achievements:**
  * Cleaned missing values and handled date conversions using `ISDATE` and `CONVERT`.
  * Removed duplicates efficiently using `CTE` and `ROW_NUMBER()`.
  * Analyzed occupancy rates, cancellation rates, and revenue generated vs. realized across cities.
